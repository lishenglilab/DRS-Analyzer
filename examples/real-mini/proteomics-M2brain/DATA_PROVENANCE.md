# DDA data provenance and attribution

M2brain is an independent laboratory mouse DDA acquisition. The example is
a curated slice of one acquisition. Source names, identifying instrument
metadata and wall-clock time were removed or generalized. The spectrum
IDs, relative retention times, precursor links and peak arrays remain
intact.

The reference is an extract of 57 full-length reviewed Mus musculus
entries from UniProtKB/Swiss-Prot, produced by the UniProt Consortium
(SIB Swiss Institute of Bioinformatics, EMBL-EBI, and PIR). All 57 frozen
canonical accessions and complete sequences matched the UniProtKB reviewed
mouse download from release 2026_04 (4 November 2026). The bulk release
label of the historical local snapshot could not be established.
The selection was made for this demonstration. FASTA headers were shortened
and lines rewrapped, retaining each accession, entry name, taxon ID and
sequence version. The amino-acid sequences are unchanged. UniProt applies
CC BY 4.0 to copyrightable database content. [UniProtKB/Swiss-Prot](https://www.expasy.org/resources/uniprotkb-swiss-prot) · [UniProt data terms](https://www.uniprot.org/api-documentation/support-data) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The laboratory mzML is released under CC BY 4.0 with attribution to
Shengli Lab / mouseDRS project. See [data terms](../DATA_LICENSE).
Retained native scan identifiers, relative retention times and peak data
can be associated with the original acquisition by its data holders.
The authors accepted that retained scientific content for this example.
