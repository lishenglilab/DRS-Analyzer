# ONT data provenance

F1-1 is a laboratory mouse direct-RNA sequencing sample. The example covers
a selection of 12 verified FASTQ/FAST5 pairs and an independent selection
of 1,500 FASTQ reads. De-identification replaces the linked read and run
identifiers and removes source metadata. The sequences, quality values,
raw signals and calibration fields remain intact. The laboratory data are released under CC BY 4.0 with attribution to
Shengli Lab / mouseDRS project. See [data terms](../DATA_LICENSE).

Retained raw signal, sequence, run-relative start offsets, read order and
channel calibration may be associated with the original acquisition by a
party who already has the source data. The authors accepted this scope.
